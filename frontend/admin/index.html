How logins work

                

                
    
                    
  • The admin login comes from ADMIN_USER / ADMIN_PASS in the env (.env on the PC, Environment Variables on Vercel). Only the admin sees this page.
    • 
                    
  • A changed page list counts at once. A new password or switching a user off logs that user out everywhere.
    • 
                    
  • Passwords are stored only as secure hashes - nobody can read them back. Forgotten password: set a new one here.
