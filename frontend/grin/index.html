Get the latest data

Three steps, in this order. Each one updates the Status page.

1Invoices from Tally
—

TallyPrime must be open with the company loaded and its XML server on: F1 Help › Settings › Connectivity › Client/Server configuration → TallyPrime acts as Both, port 9000. Companies (one per location) are set on Settings. No Tally on this PC? Drop the Tally Sales Register or a Day Book XML export in step 3 instead.

4Debit / credit notes from TAFE Channel

                    —
                

                

                

                    

                    

                    

                    

                

                
Account Info › Debit Credit Note / Intimation Details, View All – every document and what is inside it:
                    rate difference (TAFE paid the PO rate, we billed more), rejections scrapped on our account (tax invoice ZK),

SMTP_USER=accounts@yourdomain.com

Gmail / Google Workspace: use an App Password (Google account › Security › App passwords). Restart the hub after editing .env. Without it, each mail can be downloaded as .eml and sent from Outlook.
